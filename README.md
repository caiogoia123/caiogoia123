## About me

- **Data Scientist @ INTECSO**: 6-month forecast of the lab's weekly sample volume. Statistical models, LightGBM and neural networks compared in backtests; for soybean meal, monthly WAPE of 12.7% against 25% for the seasonal naive.
- **Came from BI**: Power BI and Tableau dashboards, SQL/PL-SQL on Oracle and Python pipelines at INTECSO and Coamo.
- **BSc in Computer Science (UTFPR)**: thesis on deep learning (LSTM, GRU, Mamba) for fault location in transmission lines. Currently in a graduate program in Applied Generative AI.
- In my projects, the model always has to beat a simple baseline, validated without using future data.
